# Worker Health Tracker AI

This project is an AI-based wearable system to monitor construction workers' health in real time.

It measures temperature, humidity, and heart rate using ESP32 and sensors.

The system helps in detecting abnormal conditions and predicting heat exhaustion.

## Components Used
- ESP32
- DHT11 Sensor
- Heart Rate Sensor
- OLED Display

## 🔮 Future Improvements

- Improved sensor accuracy using advanced wearable devices
